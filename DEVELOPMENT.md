# Development Guide

## Project Architecture

This project is split into three main layers:

1.  **Core (`src/core/`)**: Pure logic that transforms Schema -> React Code.
    - `Generator.ts`: The main logic. It is pure and has no side effects (does not write to disk).
    - `StyleRegistry.ts`: Manages CSS class generation.
2.  **FileSystem (`src/fs/`)**: Handles all I/O operations.
    - `FileWriter.ts`: Writes components and manifests to disk.
3.  **Facade (`src/parser.ts`)**: Maintains backward compatibility with the old `ComponentGenerator` API.

## Workflow

### 1. Making Changes
- If you are changing **how code is generated**, modify `src/core/Generator.ts`.
- If you are changing **how files are saved**, modify `src/fs/FileWriter.ts`.

### 2. Testing
We use `vitest` for testing.
- **Run tests**: `npm test`
- **Add new tests**: Create files in `src/tests/`.

### 3. Verification
Before committing, always run:
1.  `npm test` (Ensure no regressions)
2.  `npm run demo` (Ensure the end-to-end flow works)
3.  `npm run play:dev` (Optional: Visually verify in the playground)

## Playground
The playground is a Vite app located in `playground/`.
- It consumes the `manifest.json` generated by the tool.
- To update the playground with new components, run `npm run demo` (which copies the manifest).
